# 05 — GraphLayout

## Слой: Git Layer
## Файл: `src/core/git/GraphLayout.ts`
## Зависимости: types.ts

---

## Назначение

Чистая функция. Принимает массив коммитов (с parent-хешами) — возвращает layout для отрисовки графа: позиция каждого коммита (колонка), цвет, соединения с родителями.

Полностью переиспользуется из SkyFork без изменений.

## Интерфейс

```typescript
function computeGraphLayout(commits: Commit[]): GraphLayoutData
```

## Алгоритм Lane Assignment

```
Входные данные: коммиты в топологическом порядке (от новых к старым)
Структуры:
  lanes: (string | null)[]  — массив занятых lane (hash коммита-цели или null)
  colors: Map<string, string> — цвет для каждой lane

Для каждого коммита:
  1. Найти lane которая ожидает этот коммит
     - Если найдена → занять эту позицию (column = найденная lane)
     - Если нет → занять первую свободную lane (новая ветка)

  2. Освободить текущую lane

  3. Для каждого родителя:
     - Первый родитель: занять ту же lane (продолжение ветки)
     - Остальные родители: найти свободную lane (merge-линия)

  4. Записать connections: от текущей позиции к позиции каждого родителя

  5. Убрать trailing пустые lanes
```

## Цвета

12 предопределённых цветов, циклически назначаются по номеру lane:

```typescript
const COLORS = [
  '#4EC9B0', '#CE9178', '#569CD6', '#DCDCAA',
  '#C586C0', '#9CDCFE', '#D7BA7D', '#F44747',
  '#B5CEA8', '#D4D4D4', '#608B4E', '#6796E6',
];
```

## Edge Cases

- Пустой массив коммитов → `{ nodes: [], maxColumns: 0 }`
- Один коммит без родителей → одна точка в колонке 0
- Octopus merge (3+ родителей) → каждый родитель получает свою lane
- Очень широкий граф (20+ lane) → ограничение maxColumns для производительности

## Производительность

- O(n) по количеству коммитов
- Для 500 коммитов — миллисекунды
- Для 10000+ — может потребоваться пагинация на уровне вызывающего кода
