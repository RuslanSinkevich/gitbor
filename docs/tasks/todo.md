# Задачи

## 1. Markdown preview в diff

При просмотре markdown-файлов (`.md`, `.markdown`) в diff-панели — дополнительная кнопка в тулбаре.

По клику — модалка с нормальным отображением markdown (не diff с +/-).

Пример: `client-new/src/entities/pact/ui/NdsBreakdownModal/README.md`.
При правом клике по diff — контекстное меню с пунктом «Копировать»
