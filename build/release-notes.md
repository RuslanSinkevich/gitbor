- Слежение за файлами переделано: на macOS и Windows одна подписка на весь репозиторий вместо тысяч — как в Fork и VS Code. Большие репозитории открываются легче, программа меньше нагружает систему
- macOS: GitBor закрывается сразу по Cmd+Q, а не висит в доке десятки секунд
- Windows: пока GitBor открыт, папки внутри репозитория можно удалять (раньше «используется другим процессом»)
- Новые файлы, которые ещё не в git, удаляются в Корзину, а не безвозвратно; «Отбросить» на куске нового файла работает
- Поддержать проект теперь можно через CloudTips (Т-Банк): СБП, T-Pay или картой, сумма подставляется сама
- Значки заметки, закрепления и фильтра у ветки — у правого края, без пустого места

- File watching reworked: on macOS and Windows a single subscription for the whole repository instead of thousands — like Fork and VS Code. Large repositories open more easily and the app loads the system less
- macOS: GitBor quits immediately on Cmd+Q instead of hanging in the Dock for tens of seconds
- Windows: folders inside the repository can be deleted while GitBor is open (previously “in use by another process”)
- New files not yet in git are moved to the Trash instead of being deleted permanently; “Discard” on a hunk of a new file works
- Supporting the project now goes through CloudTips (T-Bank): SBP, T-Pay or card, the amount is prefilled
- Note, pin and filter marks on a branch sit at the right edge, without empty space
